# Codex Desktop Token Monitor

Codex 桌面端本地 Token 用量监控面板。读取本机 JSONL 会话日志，展示日期区间内的用量、小时趋势、缓存命中率、会话及子代理明细，并支持隐私模式和自定义模型费用估算。

无需 API Key，无 npm 运行依赖，无外部 CDN。监控程序本身不调用模型，也不消耗模型 Token。它是独立的本地工具，不是 OpenAI 官方账单系统。

## 环境要求

- Node.js 20 或更新版本。
- 本机保留了 Codex Desktop 会话日志。
- Windows 可使用附带的双击启动和停止脚本。其他系统可以通过 Node.js 命令启动；目前已在 Windows 上验证。

## 快速开始

在项目根目录执行：

```sh
npm start
```

浏览器打开 `http://127.0.0.1:4318`。自动打开浏览器可以执行：

```sh
npm run start:open
```

也可以直接运行 `node server.mjs --open`。无需先执行 `npm install`。

Windows 用户可双击 `start.cmd`。如果默认端口已经运行本工具，会直接打开现有面板。服务仅监听 `127.0.0.1`；默认端口被其他程序占用时，会自动尝试接下来的 30 个端口，以终端显示的地址为准。

## 停止服务

在启动终端按 `Ctrl+C`，或关闭启动服务的终端窗口。Windows 也可双击 `stop.cmd` 停止默认端口上的实例，包括在后台启动的实例。

非默认端口可以执行：

```powershell
powershell -File stop.ps1 -Port 4319
```

关闭浏览器标签页不会停止服务。电脑重启后需要重新启动；项目未配置开机自启。

## 配置

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `CODEX_HOME` | 用户主目录下的 `.codex` | 读取其中的 `sessions` 和 `archived_sessions` |
| `PORT` | `4318` | 起始监听端口；`--port=数字` 参数优先 |
| 页面刷新 | 5 秒 | 可暂停；标签页切回前台后立即刷新 |
| 日期时区 | 本机系统时区 | 决定日期范围、每日和每小时用量归属 |
| 模型单价 | 未设置 | 按模型和币种分别填写每百万 Token 单价，空白不表示免费 |

隐私设置和模型单价等偏好保存在当前浏览器的 `localStorage` 中，不写入仓库、Codex 配置或认证文件，也不会发送到服务器。不同浏览器或不同端口不会自动共享这些设置；清除网站数据会移除已保存的偏好。

例如，PowerShell 中指定日志目录及端口：

```powershell
$env:CODEX_HOME = 'D:\local-data\codex'
node server.mjs --port=4320
```

Windows 双击启动脚本优先检查默认端口。使用自定义目录或端口时，直接运行 Node.js 命令。

## 功能

- 预设日期区间与自定义起止日期，统一查看所选区间的输入、输出及总 Token。
- 按天或按小时查看用量趋势：日趋势对比上一等长区间，小时趋势对比所选日期与前一天，并显示日志覆盖范围。
- 缓存命中率和推理输出明细。
- 主会话 / 子代理筛选，按项目、模型或会话 ID 搜索。
- 按用量或时间排序、分页及会话详情。
- 隐私模式隐藏项目路径，并在会话列表、详情和 CSV 中使用匿名会话标识。
- 按模型填写单价，查看所选日期区间内可估算的费用及未估算用量。
- CSV 导出所有符合当前筛选条件的会话，遵循当前日期范围和隐私设置。

## 日期范围与对比

日期筛选同时影响用量汇总、趋势、费用参考和会话明细。日志中已观察到的历史日期均可查询，不局限于最近 30 天；每日和每小时桶都按运行服务的本机时区归属。

日趋势中的上一周期为所选日期范围之前的等长区间；小时趋势则展示所选日期的 24 小时用量，并与前一天的对应小时对比。

对比依赖本机现存日志的覆盖范围；未覆盖的历史不能证明没有消耗。覆盖范围仅表示首次和末次观察到用量的日期，不保证其中的日志完整。当天数据会继续增长，与已结束的完整日期对比时需留意这一点。

## 费用参考

按模型填写每百万 Token 的三个单价：未命中缓存的输入、命中缓存的输入和输出。未缓存输入使用 `input - cached`；推理 Token 已包含在输出中，不重复计费。模型单价默认留空，填入 `0` 才表示该项按免费估算。

USD 和 CNY 使用独立单价表，切换币种只切换单价表，不进行汇率换算。请填写自己希望采用的价格；工具不会联网获取价格，也不会根据模型名称自动选择单价。

费用模型归属以每次 Token 事件之前的模型记录为依据，并使用该事件的已知请求用量。首次累计快照中较早的调用、缺失调用记录造成的累计差额，以及无法确认模型的部分保留为未知模型；缺少有效单价的用量也保留为未估算。界面中的费用是可估算部分的参考值，不能视为全部消耗费用、实际账单或套餐已用额度。

## 隐私模式

开启隐私模式后，页面列表、会话详情和 CSV 导出隐藏项目路径，并使用匿名会话标识，方便截图和分享。隐私开关只改变当前浏览器的显示与导出结果。

隐私模式不是服务器访问控制，也不会修改源日志。本地 API 仍返回原始项目路径与会话标识；关闭隐私模式后导出的 CSV 也可能包含这些信息。服务保持仅监听 `127.0.0.1`，不要把本地 API 当作经过脱敏的数据接口。

## 统计口径

1. 通过 `session_meta` 识别桌面端会话及其子代理，读取 `event_msg` 中的 `token_count` 记录。
2. 用累计计数的变化量统计新增用量，跳过重复快照。按事件的本机日期和小时归入统计；首次累计快照无法还原的较早用量仍归入首次观察到它的事件时间。
3. 缓存输入已包含在输入 Token 中，推理输出已包含在输出 Token 中。总量不再重复加入这两项。
4. 归档副本按会话身份去重；子代理继承的历史记录不再次计入。子代理独立列出，不同时加进父会话一行。
5. 首次扫描完整历史，后续增量读取。正在写入的半行 JSON 等待写完后再解析。

缓存写入作为独立明细展示，不在现有总 Token 之外额外累加。CSV 汇总请使用总 Token 列。

## 数据范围与限制

- 累计用量仅代表本机现存且可识别的日志。删除的日志、其他设备和未落盘的云端任务可能不在其中。
- 工具不维护另一个历史数据库；删除源日志后，相应历史统计也会减少。
- Token 总量不等于套餐已用百分比，不能直接当作账单金额。
- 会话模型列根据所选日期范围内的逐事件模型用量显示；包含多个模型时显示“多模型 (N)”。无法归属的用量仍保留为未知模型，费用参考不会把这些用量计入最后一个模型。
- 日志计数重置或分支继承信息不完整时，只计入能够归属的用量，异常会显示在面板中。
- JSONL 是本地日志格式，可能随 Codex 版本变化；出现新格式时解析器可能需要适配。

工具只读取日志，不修改 Codex 配置、认证或会话文件。网页静态资源均在仓库中，模型单价和隐私偏好只保存在浏览器本地。
